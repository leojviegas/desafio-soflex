# Architecture Decision Records (ADRs)

Esta carpeta documenta las decisiones arquitectónicas y técnicas tomadas durante el desarrollo del **Copiloto Asistente para Operadores de Sala**. Además sirve como base directa para el archivo `DECISIONS.md` requerido en la entrega final.

## Convención de Nombres

`NNN-titulo-de-la-decision.md` (ej. `001-decisiones-arquitectura-y-stack.md`).

## Estructura Sugerida

- **Estado**: Propuesto | Aceptado | Reemplazado
- **Contexto**: Problema o definición abierta del enunciado que motivó la decisión.
- **Opciones Evaluadas**: Alternativas analizadas con sus trade-offs.
- **Decisión**: Alternativa elegida y justificación.
- **Consecuencias**: Impacto positivo y compromisos asumidos.
