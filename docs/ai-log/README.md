# Bitácora de Desarrollo con IA (`ai-log`)

Este directorio registra decisiones asistidas por IA, trade-offs y aprendizajes durante el desarrollo del desafío para nutrir `DECISIONS.md` y el video de demostración (1 a 3 minutos).

## Qué registrar

1. **Decisiones de Arquitectura y Dominio**: Por qué se eligió el stack, persistencia y estrategia dual-provider.
2. **Control de Alucinaciones**: Cómo se diseñó el esquema Zod, las evidencias textuales y `camposFaltantes`.
3. **Problemas y Correcciones**: Desvíos detectados durante pruebas reales o mock y cómo se resolvieron.
